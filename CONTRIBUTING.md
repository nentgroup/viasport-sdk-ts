# Contributing

Thank you for contributing to the Viasport TypeScript SDK.

## Prerequisites

- Node.js 24 or later
- Docker
- [Task](https://taskfile.dev/)

Install dependencies with:

```bash
npm ci
```

## Making changes

The OpenAPI specifications in `api/` are the source of truth for the generated
SDK. Do not manually edit files marked `Code generated by sdkgen. DO NOT EDIT.`

1. Create a branch from the current default branch.
2. Update the relevant OpenAPI specification in `api/`.
3. Regenerate generated SDK and documentation files:

   ```bash
   task generate:all
   ```

4. Add or update tests for behavior changes.
5. Run the relevant checks:

   ```bash
   npm run lint
   npm run prettier
   npm run typecheck
   npm test
   ```

## Pull requests

- Keep pull requests focused and include generated output when API specs change.
- Describe the consumer-facing impact and any required migration steps.

## Commit messages

We use [Conventional Commits](https://www.conventionalcommits.org/) for all
commit messages. Use the format `<type>: <description>`, for example:

```text
feat: add article search endpoint
fix: preserve response headers in SSE client
docs: clarify GitHub installation
```
